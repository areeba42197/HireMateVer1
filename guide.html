HireMate User Guide

This guide explains how to use HireMate effectively, connect LinkedIn securely, manage sessions, and generate professional hiring leads.

1. Introduction

HireMate is an AI-powered lead generation and outreach platform designed to help users discover hiring opportunities from LinkedIn, organize leads, and generate smart communication drafts.

2. System Requirements

  • Modern web browser (Chrome, Edge, Firefox)
  • Stable internet connection
  • LinkedIn account logged in on the same browser
  • JavaScript enabled

3. How to Use HireMate

  1. Open the HireMate website.
  2. Create a new account or sign in.
  3. Ensure LinkedIn is already logged in.
  4. Navigate to Dashboard to explore hiring leads.
  5. Open lead details to analyze opportunities.
  6. Generate AI-powered outreach drafts.
  7. Manage drafts from the Drafts section.

4. LinkedIn Requirement

??
LinkedIn should remain open and logged in in the same browser session for proper lead synchronization and data access.

5. Session Cookie Information

HireMate may use browser session cookies to maintain authentication, user preferences, and secure navigation during active sessions.

Cookies are used for:

  • User authentication
  • Theme preferences (Light/Dark mode)
  • Session management
  • Improved user experience

6. Security Guidelines

Never share your account password or session credentials with anyone.
  • Always logout after use on shared systems.
  • Use strong passwords.
  • Keep LinkedIn credentials secure.
  • Avoid suspicious browser extensions.

7. Dashboard Features

  • Lead Categorization
  • Hot / Warm / Cold Lead Detection
  • Draft Generation
  • Analytics Dashboard
  • Profile & Settings Management

8. Theme Support

HireMate supports both Dark Mode and Light Mode. User theme preferences are stored locally for consistent experience.

9. Conclusion

HireMate simplifies professional networking and hiring opportunity management through an industry-inspired modern interface and intelligent automation workflow.
